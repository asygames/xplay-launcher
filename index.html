Integrations

One interface, a module for each game.

Minecraft: Java Edition

Microsoft or offline accounts, profiles, Vanilla, Fabric, Quilt, Forge and NeoForge, automatic Java, Modrinth mods and modpacks, servers and a crash page with fixes.

Roblox

Several accounts side by side, a library with favorites, search by name, Place ID or link, joining a friend, and Roblox Studio.

Steam

Your library with covers, install and play, launch options per game, several accounts and a store page of games that run on Linux.

Epic Games

Sign-in, downloads and launching handled by XPlay itself, with no extra client. Free games go straight to the library.

Account security

Microsoft sign-in for Minecraft

You sign in on Microsoft's website.

XPlay uses Microsoft's official device code flow. Your Microsoft password is typed only on Microsoft's page, never in XPlay. The tokens are used for Microsoft, Xbox Live and Minecraft services and stay on your computer in an encrypted file. XPlay does not bypass game ownership.

  1. 1Open Accounts → Another account → Microsoft account.
  2. 2XPlay shows a code and copies it.
  3. 3Paste it on Microsoft's page and sign in.
  4. 4XPlay adds your Minecraft profile.
